## 建议阅读顺序

建议先建立对 FPGA 硬件资源的整体认识，再补充计算机组成基础；其余内容可根据项目需要选读。
**注意 只有FPGA资源与基础是我已经完全整理完毕 其余的并未进行整理**

### 1. FPGA 资源与基础
>我个人强烈建议先上手写过一个工程 无论是点亮LED还是什么其他的更复杂的 只有你跑到板子上知道整个流程 大致熟悉之后 你才能更好的吸收消化
>具备基础的数电知识 再进行学习 而且一上来就必须从最底层的资源上手 这样你才能知道每一行代码究竟在干什么 最终会变成什么样子 
>约束为什么这么约束 为什么不能随意约束
>资源占用率是什么意思 为什么组合逻辑不是用门电路现搭而是用LUT
>基本的单元 LUT FF是什么 他们对应的是什么逻辑
>你当然可以在一边搭建工程的过程中 一边补充自己的知识 但是我建议是先整体有个把握 在搭建复杂工程的时候 就不会只知其然而不知其所以然


1. `Logic Cell Slice CLB与FPGA Fabric`：先认识 FPGA 的整体结构。
2. `LUT` → `FF` → `MUX与Routing` → `Carry Chain`：理解基本逻辑、寄存器、布线与算术进位资源。
3. `DIstributed RAM 与 SRL` → `BRAM` → `DDR` → `FIFO`：学习片上、片外存储与数据缓冲。
4. `DSP`：了解乘加等专用算术资源。
5. `IO与BANK` → `Clock Network` → `PLL与MMCM`：理解外部接口和时钟系统。
6. `DDRIO 和 SERDES` → `High-Speed Transceiver 和 Hard IP`：最后进入高速接口与硬核资源。
7. `Timing Analysis`：建立时序约束与时序收敛意识。

### 2. 计算机组成

`计算机分类与发展方向` → `计算机系统的组成` → `计算机系统的层次结构` → `CPU及工作过程` → `存储器` → `外设` → `软件系统`

### 3. 协议与数据传输

先阅读 `通信概念`，再按需学习 `I2C`、`USB协议`、`以太网与 UDP 通信基础`；之后阅读 `分辨率`、`内存读写方式` 和 `跨时钟域CDC`。

### 4. 外设与系统设计

建议按照 `OV5640` → `时钟复位和跨时钟` → `视频流、DDR缓存与切换` 的顺序，将基础知识带入完整数据通路。

### 5. 工具与项目记录

`其他/` 中的 Vivado、PDS、Primitive、综合、布局布线及项目记录相对独立，可以在实际开发遇到对应问题时查阅。
