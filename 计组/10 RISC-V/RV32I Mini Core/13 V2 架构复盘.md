V2 版本的 cpu 可以描述为

**基于RV32I ISA 设计的一颗简化 Single-Cycle CPU 并已经实现了一组足够用于学习完整 Datapath 和 Control 的指令子集**

## 再论 ISA 与 Microarchitecture
---
ISA 描述的是 **软件能看到什么** 我们选择的是 `RV32I`
Microarchitecture 描述的是 **硬件具体怎么实现这个ISA** 我们现在选择的是 `Single-Cycle Microarchitecture`

即
>一条 Instruction 从开始到完成 所有必要的 Combinational Logic 都在一个 Clock Cycle 内走完 最后在 Clock Edge 更新 State

后续可以扩展到 `Multi-Cycle` 和 `pipeline`
的 `Microarchitecture`

## 总体架构
---
```
              Current State
                   │
          ┌────────┼────────┐
          │        │        │
          PC       RF      Data Memory
          │        │
          ▼        ▼
    ┌─────────────────────────────┐
    │                             │
    │     Combinational Logic     │
    │                             │
    │ Instruction Memory          │
    │ Decoder                     │
    │ ImmGen                      │
    │ MUX                         │
    │ ALU                         │
    │ Branch / Jump Logic         │
    │ Write-Back Logic            │
    │                             │
    └──────────────┬──────────────┘
                   │
                   ▼
               Next State
```

**Control + MUX** 就是 CPU Datapath 能支持很多不同 Instruction 的核心方法

## Single-Cycle 的特点
---
Single-Cycle 最大优点是：
```
结构直观
Control 简单
一条 Instruction 一个 Cycle
```
但缺点也很明显：
```
一个 Cycle 塞入太多工作
Clock Period 被最长路径限制
简单 Instruction 也被迫等待最长 Instruction 的时间
部分硬件资源难以跨 Cycle 复用
```

## Multi-Cycle 是我们需要的
---
可以将一条指令 分成不同周期操作 使得快指令不必迁就慢指令
