搭建我的第一个CPU!
**RV32I Mini Core v1**

## 简介
---
它是一颗：
```
32-bit
Single-Cycle
In-Order
Single-Issue
RV32I CPU
```
其中新增两个术语：
- **In-Order — 顺序执行**：指令按照程序规定的先后顺序执行和完成
- **Single-Issue — 单发射**：一个 Clock Cycle 最多开始执行一条指令

第一阶段只实现九条指令：

| 类别                   | 指令               |
| -------------------- | ---------------- |
| Register Arithmetic  | `add`、`sub`      |
| Register Logic       | `and`、`or`、`xor` |
| Immediate Arithmetic | `addi`           |
| Load                 | `lw`             |
| Store                | `sw`             |
| Branch               | `beq`            |

第一阶段实现两类 Architectural State:
`PC` 和 `Register File`

### 模块划分
```
RV32I Mini Core
│
├─ PC
├─ Instruction Memory
├─ Register File
├─ Immediate Generator
├─ ALU
├─ Main Decoder
├─ ALU Decoder
├─ Branch Logic
├─ Next-PC Logic
├─ Data Memory
├─ Write-Back Logic
└─ Top-Level Datapath
```

### 模块分类

|类型|模块|
|---|---|
|State|PC、Register File、Data Memory|
|Datapath|ALU、ImmGen、MUX、Adder|
|Control|Main Decoder、ALU Decoder、Branch Logic|
## PC
---
保存 当前Instruction Address
复位后`PC = RESET_VECTOR` 即复位向量
暂定为 `RESET_VECTOR = 32'h0000_0000`
顺序执行 `Next_PC = PC + 4`
分支成立 `Next_PC = BranchTarget`

## Register File
---
包含`x0-x31` 共 32 个 Architectural Register 每个宽度均为 32bit

特别规定 `RF[x0] = 0`
x0 是 RISC-V 的 Zero Register：
- 读取 `x0` 永远得到0；
- 向 `x0` 写入的数据必须被丢弃。

允许 '向x0内写入数据' 的指令存在 CPU也可以完成 ALU 计算 但最终不能改变 `RF[x0] = 0` 这一事实

## Memory模型
---
为了先建立真正的 Single-Cycle CPU，我们在功能仿真阶段暂定：
## Instruction Memory
```
输入：Instruction Address
输出：Instruction
读取：组合读取
写入：CPU运行期间不写
```
## Data Memory
```
输入：Address
输入：Write Data
输入：MemWrite
输出：Read Data
读取：组合读取
写入：Clock Edge写入
```
这样 `lw` 才能在一个周期内完成：
```
取指
→ 计算地址
→ 读取Data Memory
→ 形成Write-Back Data
```
等 CPU 功能完全正确后 再处理 XC7A200T BRAM 的同步读取 Latency
