移位器 **负责把一个二进制数据 整体向左或向右移动若干位**

## Shift
---
本质上是一个 **位级数据重排操作**

## Left Shift
---
例如：
```
00110110 << 1
```
结果：
```
01101100
```

可以看到：
- 每一位向高位方向移动
- 最右边空出来的位置补 0
- 最左边被推出去的 bit 被丢弃

算术左移 和 逻辑左移 效果一样 不加以区分
## Logical Left Shift
---
逻辑左移 **左边移出 右边补0**
左移在不发生高位丢失的情况下 可以等价为 `乘 2^n`

## Right Shift
---
右移 需要区分
1. Logical Right Shift 逻辑右移
2. Arithmetic Right Shift 算术右移

## Logical Right Shift
---
逻辑右移 **右边移出 左边补0**
例如：
```
10110100 >> 2
```
得到：
```
00101101
```
左侧补 0。
**逻辑右移本质上 不关心 这个数是正数还是负数**

所以 对于 unsigned value 大部分情况下 逻辑右移n位 对应着 `除以 2^n` 结果取整

## Arithmetic Right Shift
---
算术右移 考虑符号位的存在后 发现负数使用逻辑右移会出现bug
于是规定 算术右移 **右边移出 左边补原来的符号位**
- 整数补0 负数补1
例如：(补码情况下)
```
11111000
```
表示：`-8`
算术右移 1 位：
```
11111100
```
表示：`-4`
所以：`−8/2=−4`
**算术右移本质上是在进行符号位扩展**

## 移位操作的应用
---
> 位字段处理

可以通过Shift 来选取某一段bit

>Mask (掩码) 操作

配合 与或非 来对特定位进行处理

> 地址计算

在index作 `* 2^n` 计算时 可以通过移位操作来实现

> 数据打包和拆包

可以想起udp 光纤填包过程

>编码 加密 Hash(哈希)等操作

因为Shift 是一个非常基础的整数运算能力

## Shift Amount
---
移位量 表示到底要移动多少位
一般用二进制数字来表示

## Barrel Shifter
---
在需要进行 **任意移位量操作** 的时候 一级一级移肯定是不行 所以引出 **Barrel Shifter**
即 桶形移位器 可以在一次组合运算中 完成 任意指定移位量 的移位结构

**核心思想** `分解 重组`
例如 8bit数据
最大 Shift Amount : `0~7`
只需要 `3bit` 来表示 且可以把任意移位拆成 
```
1 bit 
2 bit
4 bit
```
三个阶段 (0-7中的任意一个数 均可以写成 1 2 4的组合)

于是概念上:
```
Input
  │
  ▼
[shift 1 or 0]
  │
  ▼
[shift 2 or 0]
  │
  ▼
[shift 4 or 0]
  │
  ▼
Output
```
每一级实际上由 **MUX** 控制
每一级由 Shift  Amount的位来决定
例如 第一级 由 Shift Amount[0] 决定
- s0 = 0 不移位 s0 = 1 移1位
- s1 = 0 不移位 s1 = 1 移2位
- s2 = 0 不移位 s2 = 1 移4位

所以 **Nbit数据 大概只需要 log_2 N 级选择网络**
实现形式
例如s2级：
```
Data
 │
 ├── 原位置 ──────┐
 │                 │
 └── shift 4 后 ───┤
                   ▼
                  MUX
```
然后多级级联。

## Rotate
---
循环移位 即每一位移出去后 会从另一端进入
例如：
```
10110001
```
Rotate Right 1：
```
11011000
```
**本质是 bit position的循环重新连接 也可以由Barrel Shifter 扩展支持**

## RTL实现
---
```Verilog
assign result = data << sh_amt;(shift_amount)
```
若 sh_amt 是 runtime variable 运行时可变量
那么综合器就可能映射成一个类似 Barrel Shifter 的结构 即**可变移位网络**

## Shift Register
---
移位寄存器 属于`Register Chain/State Storage` 寄存器链/状态存储
属于 **时序逻辑** 数据每个Clock移动`FF → FF → FF → FF`

而 Shifter 属于组合逻辑
