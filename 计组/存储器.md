MDR : Memory Data Register 数据寄存器 暂存数据的寄存器 用于存储从主存中读取或即将要写入主存中的寄存器

## 存储体基本概念
---
- 存储元 : 可以参考数电的存储器 是一个实在的物理器件 主要就是通过开关功能 来使得**一个存储元** 存储和读取一个二进制数
- 存储单元 : 一个存储单元由多个存储元构成
- 存储体 : 一整套包含很多存储单元的电路 称为一个**存储体**
- 存储字 : 一次可以从存储单元中读取的多位数据
- 存储字长 : 一次可以从存储单元读出多少位数据 单位bit
		  一般存储字长都是8bit的倍数 即Byte的整数倍

## 寻址范围 
---
![[Pasted image 20260906224557.png]]
由地址寄存器MAR中的地址 寻址存储体中的存储单元
n位地址对应 2的n次方个存储单元 通过译码器实现的 

>只要保证我们每次操作的数据字长一定!这样的设计就很实用 不会说指定哪个存储元 而是以存储单元为最小操作单元 这样就可以在保证存储数量一定的情况下 使用更少的选择线 也就可以减少地址线 反过来说 也就是同样数量的地址线 可以存储的数据更多!

可以看到总容量计算公式 很容易理解 3个地址的存储器 可以存储8B的数据

## 数据寄存器 MDR
---
从存储单元中取出的数 会送到数据寄存器中
存储单元的存储字长 = 数据寄存器的位数

## 容量
---
![[Pasted image 20260909151840.png]]
总容量 = 存储单元个数 X 存储字长 bit 
		=存储单元个数 X 存储字长/8 Byte

从地址来看 n位地址对应2的n次方个存储单元
系统能支持的最大**容量 = 2^n X 存储字长**
n其实就是地址寄存器的位数

区分最大容量和总容量 
最大容量是指译码器能够驱动的存储元
总容量是指一块存储体所能存储的数据量
